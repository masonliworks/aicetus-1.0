01 — 功能

电脑上的智能体，手机上的遥控器

A 远程审批

智能体要执行 npm install、删文件、改数据库？高危操作实时推送到手机，批准或拒绝，一键定夺。人不在电脑前，也不会卡在等待。

B 实时看管

会话状态、目标进度、任务清单秒级同步到手机。跑没跑完、卡在哪一步，扫一眼就知道。

C 排队与插话

想到新需求随手发：排队模式不打断当前任务，做完自动执行；插话模式立即纠偏，方向不对当场喊停。

D 局域网直连

手机与 Mac 通过局域网 WebSocket 直连，扫码即配对。你的代码和对话不经过任何第三方服务器。

02 — 上手

三分钟，把手机接上你的 Mac

第一步

Mac 装上伴侣 App

下载 macOS 版并启动，桥接服务自动运行在 :7820，菜单栏常驻不打扰。

第二步

手机扫码配对

iOS 端打开「设置 → 扫码配对」，对准 Mac 屏幕上的二维码，地址与 Token 自动填入。

第三步

开始遥控

会话、审批、日志全部出现在手机上。去倒杯咖啡，智能体照样听你指挥。
