# 小红书推文（开发者版）：掌中鲸

## 🐋 安利一个我每天都在用的效率工具：掌中鲸

先说背景：我是那种会让 AI Agent 在 Mac 上跑长任务的开发者——DeepSeek Harness 挂着，一堆 workflow 排队执行。

以前最痛苦的场景：
1. 人在外面，AI 执行到一半要审批工具操作，不点就一直卡着，等我回来黄花菜都凉了
2. 去倒杯水的功夫，AI 报错了，回来才发现浪费半小时
3. 想在床上看两眼任务进度，得跑回书房

**掌中鲸解决的就是这个"人机分离"的问题。**

### 作为开发者，它打动我的几个点：

**1. 会话是完整重建的，不是简单推送**
手机上能看到完整对话历史，实时跟进每一步执行。对 Agent 来说，你不在电脑前也能精确掌握它"想干什么、干到哪了"。

**2. 审批真的能在手机上一键处理**
Agent 请求执行 shell/写文件之类的操作时，手机直接批/拒，还能回答它的问题——相当于把"人在回路"（human-in-the-loop）的环节搬到了口袋里。

**3. 扫码配对，安全性设计得克制**
密钥存在设备本地、Token 认证、Mac 的 DSH 端口不暴露到局域网、数据只在 iPhone 和 Mac 之间流动。不收集数据、无广告——对开发者来说，这种"不越界"的设计很加分。

**4. 通知到位**
审批请求、提问、报错实时推送，重要节点不错过。

### 🚀 展望 2.0：广域网连接

目前 1.0 是局域网方案（iPhone 和 Mac 同一 Wi-Fi）。
**2.0 的重点方向是广域网连接**——让你不在家也能连上 Mac 上的 AI：
- 出门在外直接控制家里的 Mac 跑任务
- 出差途中审批、跟进、指挥你的 AI 打工仔
- 相当于你的 AI 真正变成"随时在线"的远程员工

这会是质变：从"局域网遥控器"变成"真正的远程控制台"。

### 总结

如果你也是重度 AI Agent 用户，掌中鲸值得一试。
iOS 17+，App Store 搜 **掌中鲸**，Mac 端伴侣 App 免费。
