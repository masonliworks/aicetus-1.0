# DSH Remote — iOS 端 UI 设计标准（v0.3）

> 本文档供 UI 设计师执行界面设计。功能与数据流已实现，本规范定义**视觉与交互标准**。
> 目标平台：iPhone（iOS 17+），原生 SwiftUI。设计稿以 390×844 pt 为基准，覆盖浅色/深色双模式。
> 版本 v0.3：新增流式显示、队列卡片、工作区分栏、模型 popover、会话管理、底部信息栏。

---

## 1. 产品概述

DSH Remote 是「DeepSeek Harness」的 iPhone 远程控制端。用户在手机上实时操控跑在 Mac 上的 AI Agent：

- **会话**：工作区分栏的会话列表；对话页完整历史 + **流式实时输出**；排队/插话两种发送方式
- **审批**：工具调用批准/拒绝、Agent 提问应答（会话内嵌呈现）
- **目标 / 任务**：会话内目标条（含创建）、任务条
- **配对**：Mac 伴侣 App 二维码扫码即连

**情绪基调**：专业、可信、克制。这是 Agent 的"遥控驾驶舱"——信息密度优先，装饰从简。

---

## 2. 信息架构

```
App
├── 会话（唯一首页 Tab，按工作区分栏）
│   └── 会话详情（对话，全屏无 Tab）
│        └─ 详情内自上而下：消息列表（含流式）→ 队列卡片区 → 目标条 → 任务条 → 审批条
│           → 底部信息栏（模型/上下文圆环/命令）→ 输入栏（排队/插话切换 + 发送/停止）
└── 设置（Tab）
     ├─ 桥接服务地址 + Token
     ├─ 扫码配对
     └─ 连接状态 / 关于
```

**核心原则**：审批、目标、任务不是独立页面，而是"会话的组成部分"——只在会话详情页以紧凑组件呈现，有内容才显示。

---

## 3. 设计原则

1. **状态可感知**：连接/运行/等待审批/排队，任何状态用颜色+图标+文字三重编码。
2. **一键可达**：允许一次 / 拒绝 / 插话引导 / 切换发送模式，不超过两次点击。
3. **内容优先**：对话与流式输出是主角；审批/目标/队列是"插曲"，用收窄卡片呈现。
4. **克制用色**：彩色只用于状态与语义，界面骨架用中性色。

## 4. 设计 Tokens

### 4.1 颜色（语义色，深浅模式各一套）

| 语义 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `background.base` | `#F2F2F7` | `#000000` | 页面底色 |
| `surface` | `#FFFFFF` | `#1C1C1E` | 卡片/气泡/输入框 |
| `surface.raised` | `#FFFFFF` | `#2C2C2E` | 弹层、表单分组 |
| `text.primary` | `#000000` | `#FFFFFF` | 正文 |
| `text.secondary` | `#3C3C43 60%` | `#EBEBF5 60%` | 次要信息 |
| `text.tertiary` | `#3C3C43 30%` | `#EBEBF5 30%` | 时间戳、占位 |
| `divider` | `#3C3C43 20%` | `#545458 65%` | 分隔线 |
| `accent` | `#0A84FF` | `#0A84FF` | 主按钮、链接、选中 |
| `status.running` | `#30D158` | `#30D158` | 运行中 / 已连接 |
| `status.idle` | `#8E8E93` | `#98989D` | 空闲 / 未连接 |
| `status.waiting` | `#FF9F0A` | `#FFD60A` | 待审批 / 排队中 / 连接中 |
| `status.danger` | `#FF3B30` | `#FF453A` | 拒绝 / 错误 / 删除 |
| `status.complete` | `#007AFF` | `#0A84FF` | 已完成 |

**规则**：语义色仅用于状态点、徽标、图标、危险/确认按钮；大面积区块用中性色 + 低透明度语义色底（如待审批卡片 `waiting` 10% 透明底）。

### 4.2 字体（系统字体，不引入自定义）

| Token | 字号/字重 | 用途 |
|---|---|---|
| `title` | 17 / semibold | 页面标题 |
| `headline` | 17 / semibold | 列表项标题、卡片标题 |
| `body` | 15 / regular | 正文、对话内容 |
| `subheadline` | 15 / regular | 卡片说明、队列卡片正文 |
| `footnote` | 13 / regular | 辅助信息 |
| `caption` | 12 / regular | 徽标、状态文字、思考摘要 |
| `caption2` | 11 / regular | 时间戳、极细标注 |

- 行高：正文 1.4，标题 1.2。
- 代码/路径/参数/工具结果用等宽字体（SF Mono），配浅色底块。

### 4.3 间距（8pt 栅格）

| Token | 值 | | Token | 值 |
|---|---|---|---|---|
| `space.1` | 4 | | `space.4` | 16 |
| `space.2` | 8 | | `space.5` | 20 |
| `space.3` | 12 | | 页面左右留白 | 16 |

### 4.4 圆角

| Token | 值 | 用途 |
|---|---|---|
| `radius.sm` | 8 | 小徽标、代码块 |
| `radius.md` | 12 | 卡片、输入框、抽屉 |
| `radius.lg` | 16 | 消息气泡、大卡片 |
| `radius.pill` | 999 | 胶囊标签 |

### 4.5 阴影 / 层级 / 图标

- 仅弹层用阴影；列表卡片**不用阴影**，用底色差 + 圆角区分。
- 横幅、审批条、队列卡片区、信息栏用 `.bar` 材质（跟随系统模糊）。
- SF Symbols 线框风格：运行 `circle.fill`；空闲 `circle`；待审批 `exclamationmark.shield.fill`(橙)；提问 `questionmark.circle.fill`(橙)；目标 `target`；任务 `hammer`；排队 `text.line.last.and.arrowtriangle.forward`；插话 `arrow.up.right.circle`；思考 `brain.head.profile`；工具 `wrench.and.screwdriver`；编辑 `pencil`；删除 `trash`；停止 `stop.circle.fill`(红)。

## 5. 组件规范

### 5.1 状态指示（StateIndicator）
圆形 8pt + caption 文字。已连接(绿)/连接中(黄)/未连接(灰)/失败(红)。

### 5.2 工作区分栏（WorkspaceSection）
- 列表按工作区分组，Section 头：📁 图标 + 工作区名(caption semibold) + 路径(caption2 tertiary, 1行截断)。
- 未归类会话放最后（无 header 或"其他"）。

### 5.3 会话行（SessionRow）
- 左：标题(headline, 1行) + 状态行(状态点 + 运行中/空闲 + preset 胶囊) + 🎯 活动目标摘要(footnote, 仅未完成目标)。
- 右：上=待审批徽标(红盾牌+数字，仅有待办时)，下=相对时间(静态"5分钟前"文本，不实时跳动)。
- 左滑手势：归档(红) / 分叉(蓝) / 重命名(橙)。

### 5.4 消息气泡（MessageBubble）
- 用户：右对齐，accent 15% 底，radius.lg，max-width 78%。
- Agent：左对齐，surface 底，radius.lg，max-width 88%，文本可选可复制。
- Agent 气泡内部自上而下：**[思考过程抽屉] → [工具调用抽屉×N] → [正文文本]**。

### 5.5 思考过程抽屉（ReasoningDrawer）
- 收起态：`› 🧠 思考过程`（caption, secondary）。
- 展开态：浅灰块(radius.sm) 内显示思考全文（callout, secondary），可复制。
- 默认收起。

### 5.6 工具调用抽屉（ToolCallDrawer）
- 收起态一行：`› 🔧 工具名 + 结果摘要(caption2, 1行截断) + 状态图标`（✓绿完成 / ✗红失败 / 转圈橙执行中）。
- 展开态：参数 JSON 块（等宽 caption）+ 结果块（等宽，失败红底 8%）。
- 每个工具调用一个抽屉，独立展开。

### 5.7 流式气泡（StreamingBubble）
- 位置：消息列表最后。
- 内容：思考中行（🧠 + "思考中…" + 最近思考文字 2 行截断）+ 正文气泡实时增长；首 token 前显示 ProgressView + "生成中…"。
- 视觉上明显区别于完成消息（可加轻微脉冲/呼吸动效）。

### 5.8 队列卡片（QueueCard）
- 位置：消息列表下方、目标条上方，卡片区 `.bar` 材质。
- 结构：状态徽标（⏱ 排队中=橙 / ↗ 引导发送中=蓝）+ 正文(subheadline, 4行截断) + 三操作图标：✏️编辑(弹窗改文) / ↗插话引导(排队中可点，引导中置灰) / 🗑️删除(红)。
- 卡片底 surface，radius.md。

### 5.9 审批卡 / 提问卡
- 审批卡：`waiting` 10% 底 + radius.md；标题行(盾牌+"工具调用待审批"+工具名胶囊) → 原因(subheadline secondary, 3行) → [拒绝(红 bordered) | 允许一次(borderedProminent)]。
- 提问卡：同族，questionmark 图标橙色；单选圆圈/多选方框；提交/跳过。

### 5.10 目标条（GoalStrip）/ 任务条（JobStrip）
- 目标条：阶段 emoji + 摘要(caption 1行) + 操作图标（暂停⏸/恢复▶/完成✓）；无目标时显示「+ 创建目标」入口。
- 任务条：最多 3 条任务行（状态图标 + 名称 + 状态文字）。

### 5.11 底部信息栏（SessionStatusBar）
- 输入栏上方一条 `.bar` 材质横栏，左→右：
  1. **模型胶囊**：🖥 模型名 + `· effort` + chevron（点击弹 popover 选择器）
  2. **上下文圆环**：16pt 圆环（用量百分比），>85% 红色；旁标"上下文 NN%"
  3. **+ 命令按钮**：点击弹菜单（/compact /feedback /goal）
- 圆环动画：用量变化时平滑过渡。

### 5.12 模型选择 popover（ModelPicker）
- **小气泡**（非全屏），锚定模型胶囊，max-width 340、max-height 420。
- 顶部标题"模型与思考强度" + 关闭 ✕。
- 内容：provider 分组(caption semibold) → 每行 [勾选圈 + 模型名 + "思考强度 · Off/High/Max"(caption2)]，当前项实心勾选。
- 点击行即切换并收起。

### 5.13 输入栏（Composer）
- 左：**模式胶囊**（40pt 宽，图标+文字竖排）："排队"（默认，secondary）/ "插话"（accent，高亮）。
- 中：多行输入框(1-5行)，键盘工具栏带"完成"收起按钮。
- 右：会话运行中=红色停止键；空闲=accent 发送键（空文本置灰）。

### 5.14 空态 / 错误态 / 加载态
- 空态：SF Symbol + 标题 + 一句说明，图标 secondary。
- 加载历史："加载历史…"占位视图。
- 错误：alert 或横幅红字，可操作建议。

## 6. 页面规范

### 6.1 全局连接横幅
- 固定顶部 32pt `.bar`。内容：状态点 + "已连接 · N 个会话运行中 · 模型名"(caption)；DSH 不可达时红色"已连接 · DSH 无法访问"。

### 6.2 会话列表（首页）
- 工作区分栏（§5.2）；导航栏"会话" + 右上角 `+`。
- Tab 角标 = 全局待审批+待回答总数。
- 自动刷新（5s）+ 下拉刷新；归档会话不显示。
- 空态：无会话提示。

### 6.3 会话详情（对话）— 核心页面
- **全屏**（进入后隐藏 Tab bar）；导航栏标题 inline。
- 布局自上而下：消息列表(含流式) → [队列卡片区] → [目标条/创建目标] → [任务条] → [审批条] → [底部信息栏] → [输入栏]。
- **消息列表**：完整历史 + 实时流式；默认定位最新消息，新内容自动滚底；滚动即收键盘。
- 点击连接横幅进设置；长按气泡复制（系统菜单）。

### 6.4 设置
1. "桥接服务"：地址 + Token（可显示/隐藏）+ 脚注。
2. "配对"：**[ 扫码配对 ]** 大按钮 → 相机取景页 → 扫到 `dshremote://` 自动填充并连接，成功震动。
3. "连接"：连接/保存并重连；已连接时显示断开。
4. "连接状态"：状态 / DSH 版本 / 当前模型 / 错误。
5. "关于"。

### 6.5 弹层清单
- 新建会话 sheet：工作区 Picker + Agent 预设 Picker（含描述）+ 创建/取消。
- 创建目标 sheet：objective 多行输入 + 轮次上限 + 创建/取消。
- 回答提问 sheet：问题列表 + 选项 + 提交/跳过。
- 模型选择 popover（§5.12）。
- 编辑消息 alert：多行输入 + 保存/取消。

## 7. 交互规范

| 交互 | 规范 |
|---|---|
| 发送模式 | 默认排队；点模式胶囊切换；插话模式高亮为 accent |
| 队列卡片 | 编辑/引导/删除图标操作，操作中整卡禁用；引导中状态不可再引导 |
| 流式 | 思考与正文实时增长；完整消息到达时流式气泡消失并落库 |
| 手势 | 列表下拉刷新；左滑会话行出三操作；滚动消息区收键盘 |
| 导航 | 列表→详情 push；提问/新建/创建目标 sheet；模型选择 popover |
| 反馈 | 异步操作加载态；审批成功卡片即时移除 + 轻震动；失败 alert |
| 通知 | 待审批/提问/报错本地通知；点击直达对应会话 |

---

## 8. 无障碍与适配

- 颜色状态必配图标/文字；支持 Dynamic Type；触控目标 ≥44pt；深浅模式完整适配；对话页支持横屏。

---

## 9. 给 UI 设计师的交付要求

1. **设计稿**：§6 全部页面 × 浅色/深色；含流式状态、队列卡片三种状态、空/加载/错误态。
2. **组件库**：§5 全部组件 symbol 化，标注尺寸与状态变体（重点：抽屉组件展开/收起两态、队列卡片三态、圆环动画）。
3. **Token 表**：§4 token 落地为设计变量，命名与代码一致。
4. **标注**：间距、字号、圆角、颜色精确标注；SF Symbols 命名对照。
5. **可执行**：能在 SwiftUI 以系统组件 + 本文档 token 还原；避免无法映射的自定义控件（除二维码、相机取景、圆环外）。

### 交付优先级
- **P0**：会话详情全貌（流式气泡、思考/工具抽屉、队列卡片、底部信息栏、输入栏模式切换）、会话列表（分栏+徽标）。
- **P1**：模型 popover、审批/提问卡、新建会话/目标表单、设置页。
- **P2**：扫码配对页、空态/错误态细节、动效微调（流式呼吸、圆环过渡）。
